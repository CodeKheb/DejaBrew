# Scenes

Contains the main Blender scene for the final animation.

## What Goes Here

- `main.blend` — Master scene where the complete animation is assembled.
- Camera setup and movement.
- Final object placement.
- Animation and timing.
- Final lighting adjustments.

## Rules

- Only the assigned integrator should edit `main.blend` at a time.
- Link assets from `assets/` whenever possible instead of duplicating them.
- Always pull the latest changes before editing.
- Use relative paths for external resources.
