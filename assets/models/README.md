# Models

Contains the Blender files for individual 3D models used in the animation.

## What Goes Here

- Characters
- Props
- Environment models
- Furniture and decorations
- Other 3D objects

## Rules

- Use separate `.blend` files when multiple teammates are working simultaneously.
- Give objects and collections descriptive names.
- Avoid editing another teammate's model without coordinating first.
- Models should be linked into `scenes/main.blend` when possible.
