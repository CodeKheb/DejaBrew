# Textures

Contains images and textures used by Blender.

## What Goes Here

- PNG images
- JPG images
- Logos
- Texture maps
- Normal maps
- Roughness maps
- Other image resources

## Rules

Always use relative paths when referencing these files from Blender.

Do not reference files directly from personal directories such as:

`Downloads/`

`Desktop/`

`Documents/`

For example, `DejaBrew_Logo.png` should be stored here instead of inside someone's Downloads folder.
