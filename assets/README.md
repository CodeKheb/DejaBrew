# Assets

Contains all reusable resources used by the Blender project.

## Directories

- `models/` — 3D models, props, characters, and environments.
- `materials/` — Reusable materials and shaders.
- `textures/` — Images, logos, and texture maps.
- `audio/` — Music, sound effects, and other audio files.

Assets should be created separately when possible and linked into the main scene.
